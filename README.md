# Typography Guide

Guide typographique pour apps de lecture (Substack / Medium grade), avec showcase HTML standalone.

## Contenu

- **`index.html`** : showcase typographique standalone qui applique toutes les règles. Toggle dark mode, responsive mobile/desktop, polices Source Serif 4 + Inter via Google Fonts.
- **`TYPOGRAPHY_GUIDE.md`** : guide complet, recommandations chiffrées (font-size, line-height, spacing) pour desktop et mobile, comparatif des refs du marché, quick fix CSS prêt à coller.

## TL;DR

> **19 / 1.65 / 740px** sur desktop. **17 / 1.6 / pleine largeur** sur mobile (serif).
> Body en **Source Serif 4**, titres en **Inter**.
